# Script Reader

Script Reader یک وب‌اپ استاتیک و آفلاین‌محور برای مطالعهٔ نمایشنامه، تمرین نقش و نمایشنامه‌خوانی گروهی است. برنامه با Vue 3 ساخته می‌شود، روی GitHub Pages اجرا می‌شود و به بک‌اند، حساب کاربری یا دیتابیس سرور نیاز ندارد.

## قابلیت‌های نسخهٔ 1.0

- کتابخانهٔ محلی نمایشنامه‌ها با IndexedDB.
- ساختار پرده، صحنه، دیالوگ، گفتار، توضیح داخل دیالوگ و توضیح صحنه.
- هایلایت نقش‌ها همراه با رنگ قابل‌تغییر، تعداد دیالوگ، تعداد و سهم کلمات گفتاری، زمان تقریبی گفتار و timeline قابل کلیک.
- تنظیم اندازه متن، فاصله خطوط، خانواده فونت، تم روشن/تیره و نمایش توضیحات صحنه.
- جست‌وجوی متن با حرکت بین نتیجهٔ قبلی و بعدی.
- حالت تمرین با انتخاب «نقش من»، حرکت بین دیالوگ‌های نقش، حالت فقط cue و دیالوگ خود، و سه روش آشکارسازی: مخفی کامل، سه کلمه اول و آشکارسازی مرحله‌ای.
- حالت نمایشنامه‌خوانی با تمرکز روی یک بلوک جاری.
- نشانک و یادداشت برای هر سطر.
- ورود و خروج JSON همراه با اعتبارسنجی ساختار تو در تو؛ متن واردشده هرگز به‌صورت HTML خام رندر نمی‌شود.
- جلوگیری اختیاری از خاموش‌شدن صفحه با Screen Wake Lock و خواندن نقش‌های دیگر با Speech Synthesis مرورگر.
- PWA و استفاده آفلاین پس از اولین بارگذاری موفق.
- رابط فارسی RTL و واکنش‌گرا.

نمایشنامهٔ همراه پروژه عمداً فقط یک fixture کوتاه برای نمایش قابلیت‌هاست و انتشار نسخهٔ کامل یک اثر نیست. محتوای واقعی باید از طریق فرمت JSON وارد شود و مسئولیت داشتن حق استفاده از متن با استفاده‌کننده است.

## توسعه

```bash
npm ci
npm run typecheck
npm run test:run
npm run build
npm run dev
```

مسیر production در GitHub Pages برابر `/script-reader/` است.

## فرمت داده

مرجع اصلی مدل داده `src/types.ts` است و نمونهٔ آن در `docs/play-format.md` آمده است. توضیحات اجرایی داخل دیالوگ به‌صورت صریح از گفتار جدا می‌شوند و دیگر با regex از روی پرانتز حدس زده نمی‌شوند.

## انتشار

هر PR که در `master` merge شود یک release مستقل است. هر PR باید `VERSION` را افزایش دهد، بخش تاریخ‌دار متناظر در هر دو changelog فارسی و انگلیسی داشته باشد و validator نسخه و CI فرانت‌اند را پاس کند.

جزئیات در `CONTRIBUTING.md`، `AGENTS.md` و `docs/pull-request-review-deployment.md` آمده است.

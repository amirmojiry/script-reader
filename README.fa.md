# Script Reader

Script Reader یک وب‌اپ استاتیک و آفلاین‌محور برای مطالعهٔ نمایشنامه، تمرین نقش و نمایشنامه‌خوانی گروهی است. برنامه با Vue 3 ساخته می‌شود، روی GitHub Pages اجرا می‌شود و به بک‌اند، حساب کاربری یا دیتابیس سرور نیاز ندارد.

## قابلیت‌های نسخهٔ 1.6

- کتابخانهٔ محلی نمایشنامه‌ها با IndexedDB.
- ساختار پرده، صحنه، دیالوگ، گفتار، توضیح داخل دیالوگ و توضیح صحنه.
- شش نمایشنامهٔ همراه تأمین‌شده توسط کاربر: «اسب‌های پشت پنجره»، «مهمان ناخوانده» اثر اریک امانوئل اشمیت با ترجمهٔ تینوش نظم‌جو، «حساب پرداخت نمی‌شه!» اثر داریو فو با ترجمهٔ حامد جهانشاهی، و سه اثر چیستا یثربی شامل «بانو و مرد مرده»، «جنایت و مکافات» و «عکس دسته جمعی با خانم بزرگ».
- فیلتر کتابخانه بر اساس تعداد شخصیت، مدت تقریبی، نویسنده، مترجم و ژانر و مرتب‌سازی بر اساس عنوان، مدت و تعداد نقش.
- ویزارد انتخاب نمایش برای پیشنهاد نمایش مناسب بر اساس تعداد افراد، تعداد مرد/زن، زمان در دسترس و ژانر دلخواه.
- سه شاخص هر کارت نمایشنامه و دکمهٔ «باز کردن» در یک چیدمان هم‌اندازه و منظم نمایش داده می‌شوند.
- هایلایت نقش‌ها همراه با رنگ قابل‌تغییر، جنسیت نقش، تعداد دیالوگ، سهم کلمات گفتاری، زمان تقریبی گفتار، timeline قابل کلیک و RTL و دکمهٔ «شروع» برای پرش به اولین دیالوگ نقش.
- نقش مجازی «راوی» برای توضیحات صحنه، توضیحات صریح داخل دیالوگ و بخش‌های پرانتزی گفتار؛ رنگ/هایلایت و انتخاب راوی به‌عنوان «نقش من» برای هر نمایش ذخیره می‌شود.
- Vazirmatn به‌عنوان فونت پیش‌فرض و انتخاب بین Noto Sans Arabic، Noto Naskh Arabic، Amiri، Lalezar، Katibeh و Parastoo.
- صفحهٔ مستقل تنظیمات خارج از صفحهٔ هر نمایشنامه برای اندازه متن، فاصله خطوط، فونت، تم روشن/تیره، نمایش توضیحات صحنه و Wake Lock. تنظیمات در IndexedDB ذخیره و بعد از جابه‌جایی بین صفحات، رفرش و بازکردن دوبارهٔ برنامه بازیابی می‌شوند.
- پنل نقش‌ها کاملاً جمع می‌شود؛ در موبایل صفحه با نقش‌های بسته باز می‌شود و دکمهٔ بستن داخل خود پنل باقی می‌ماند تا همیشه در دسترس باشد.
- جست‌وجوی متن با حرکت بین نتیجهٔ قبلی و بعدی.
- حالت تمرین با انتخاب «نقش من»، حرکت بین دیالوگ‌های نقش، حالت فقط cue و دیالوگ خود، و سه روش آشکارسازی: مخفی کامل، سه کلمه اول و آشکارسازی مرحله‌ای.
- حالت نمایشنامه‌خوانی با تمرکز روی یک بلوک جاری.
- نشانک و یادداشت برای هر سطر.
- ورود و خروج JSON همراه با اعتبارسنجی ساختار تو در تو؛ متن واردشده هرگز به‌صورت HTML خام رندر نمی‌شود.
- جلوگیری اختیاری از خاموش‌شدن صفحه با Screen Wake Lock و خواندن نقش‌های دیگر با Speech Synthesis مرورگر.
- PWA و استفاده آفلاین پس از cache warm-up؛ stylesheet و فایل‌های Google Fonts نیز با Service Worker cache می‌شوند.
- رابط فارسی RTL و واکنش‌گرا.

## توسعه

```bash
npm ci
npm run typecheck
npm run test:run
npm run build
npm run dev
```

مسیر production در GitHub Pages برابر `/script-reader/` است.

## فرمت داده

مرجع اصلی مدل داده `src/types.ts` است و نمونهٔ آن در `docs/play-format.md` آمده است. برای نمایش‌های curated جدید باید جنسیت هر نقش و حداقل یک ژانر ثبت شود؛ اگر جنسیت از منبع مشخص نباشد `unknown` استفاده می‌شود. راوی یک نقش مجازی است و توضیحات صحنه، directionهای صریح و بخش‌های پرانتزی متوازن داخل دیالوگ را می‌خواند؛ متن منبع برای این کار بازنویسی نمی‌شود. دادهٔ نمایشنامه‌های همراه به‌صورت deterministic به مدل استاندارد تبدیل می‌شوند.

## انتشار

هر PR که در `master` merge شود یک release مستقل است. هر PR باید `VERSION` را افزایش دهد، بخش تاریخ‌دار متناظر در هر دو changelog فارسی و انگلیسی داشته باشد و validator نسخه را پاس کند؛ تغییرات مؤثر بر اپلیکیشن همچنین CI کامل فرانت‌اند را در حالت Ready پاس می‌کنند.

جزئیات در `CONTRIBUTING.md`، `AGENTS.md` و `docs/pull-request-review-deployment.md` آمده است.

## [1.0.0] - 2026-09-17

### Added
- Initial Vue 3 + TypeScript Script Reader application with library, reader, rehearsal, and table-read modes.
- Structured play schema separating spoken text, inline directions, and stage directions.
- Character highlighting, word/dialogue statistics, role timelines, scene navigation, bookmarks, and JSON import/export.
- IndexedDB persistence, offline PWA caching, optional Screen Wake Lock, and speech synthesis for other roles.
- Vitest tests plus optimized GitHub Pages CI/deployment.
- Agent, contribution, architecture, release, deployment, and roadmap documentation in Persian/English where appropriate.
